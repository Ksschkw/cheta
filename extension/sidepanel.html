Reference

Commands

  • /start greet, and show what I already remember.
  • /memories show every note I have stored about you.
  • /forget 2 retire a note so I stop bringing it up.
  • /pair get a one-time code to add another client.
  • /sessions list the clients sharing your memory space.
  • /unpair 2 leave the shared space, or remove a listed client.
  • /name Kosisochukwu set your name across all sessions.
  • /help this full reference.

Commands are typed as normal messages.

What the tools do

  • Search the web, read a page you name, check Wikipedia or the weather.
  • Do arithmetic and set or list reminders.
  • Answer questions about a document you send; voice notes are transcribed.

Pairing

Type /pair on a client you already use to get a one-time code, then type /pair and that code on the new client.

Memory

Each reply lists what was recalled for it. "Show it without memory" replays that turn with memory off, so you can see the difference. The Memory switch turns memory off for one message only.
