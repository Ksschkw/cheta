Cheta Master Tutorial

1. The 4 Unified Surfaces

Cheta is unified across 4 platforms with a single shared Walrus decentralized memory space:

  • Browser Extension (Sidepanel): In-page WebMCP automation, live reasoning pills, tab reading, and instant APK/file download buttons.
  • Telegram Bot: Mobile companion. Remembers what you did on your laptop or terminal.
  • Terminal CLI: python -m src.cli chat for developer workflows and terminal memory.
  • Web Dashboard: Accessible via /app/ for complete memory inspection and settings.

2. Decentralized Walrus Memory

Talk naturally! Cheta automatically detects durable facts about you, your projects, and preferences, encrypts them, and commits them to Walrus storage blobs.

  • /memories — lists every active note stored about you.
  • /forget <number> — permanently retires a memory note.
  • /correct <number> <text> — edits the exact wording.

3. 10-Second Cross-Device Pairing

Want your Telegram bot or Terminal to share the exact same memories as this browser?

  1. Click Profile above (or type /pair) to get a 6-digit code.
  2. Open your other client (e.g. Telegram or CLI) and type pair <code>.
  3. Done! Both surfaces now read and write to the same Walrus memory space.

4. Proactive Web Crawler & 1-Click Downloads

Extract knowledge and direct download links from any public website:

  • Type /crawl https://example.com or crawl <url>.
  • Cheta inspects robots.txt, traverses pages, extracts key content, and surfaces prominent Download Buttons for discovered APKs, ZIPs, and PDFs.

5. In-Page WebMCP DOM Automation

Click Read Tab on any webpage. On sites exposing WebMCP tools (like the Pizza Maker demo), Cheta registers their capabilities and can execute actions directly inside the webpage when you ask (e.g. "add mushrooms and make it large")!

6. Complete Command Reference

  • /tutorial — print this master tutorial.
  • /crawl <url> — crawl website and extract download links.
  • /start — greet and view remembered facts.
  • /tools — list all registered agentic capabilities.
  • /name <name> — set your display name across all clients.
  • /sessions — view all connected devices.
  • /unpair — disconnect this device from the shared memory space.
