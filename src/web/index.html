Help

Commands

  • /help shows this reference.
  • /memories shows everything stored about you, numbered.
  • /forget 2 retires the note with that number.
  • /start says hello and recalls what is known about you.
  • /link <handle> joins a shared memory space across your clients.

Commands are typed as normal messages. Nothing has to be guessed: whatever you can do has a visible control.

What the tools do

  • Search the web, read a page you name, check Wikipedia or the weather.
  • Do arithmetic and set or list reminders.
  • Answer questions about a document you send; voice notes are transcribed.

Memory

Each reply lists what was recalled for it. "Show it without memory" replays that turn with memory off, so you can see the difference. The Memory switch turns memory off for one message only.

Welcome to Cheta

Cheta is a memory-first assistant: it remembers what you tell it and shows you what it remembered.

What it does

  • Remembers what you tell it.
  • Shows exactly what it remembered under each reply, and re-answers with memory off so you can see the difference.
  • Can be corrected or emptied at any time.
  • Works on Telegram, the command line, this browser page, and a browser extension.
  • Your memory follows you between them once you pair them.

Pairing

Generate a pairing code on a client you already use, then enter it on the new one.

What it cannot do

  • It cannot log into your accounts.
  • It cannot read private pages you are not viewing.
  • It cannot see images, audio, or video beyond voice transcription.
