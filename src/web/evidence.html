Self-Healing Index Recovery

Walrus Memory does not provide a listing endpoint to enumerate blobs. Cheta periodically snapshots its SQLite index into a companion namespace (*.idx). When the application database is completely wiped or redeployed on Render: 

POST /memories/{user_id}/rebuild-index
Response: 200 OK
{
  "snapshots_scanned": 5,
  "records_recovered": 19,
  "records_already_present": 0,
  "namespace": "ranti.user.telegram-6190892934.idx"
}
→ Full state restored from Walrus without data loss.
