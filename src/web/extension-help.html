CHETA

Install the extension

The extension is not published to any store. It ships as two unpacked builds from this repository: one for Chrome and Edge, and one for Firefox. Chrome and Edge keep an unpacked extension between restarts. Firefox loads it as a temporary add-on, which is removed when Firefox restarts and has to be loaded again.

Quick Install (No Terminal or Python Needed)

If you downloaded the pre-packaged zip directly from the portal, you do not need git or python:

  • Chrome, Brave, Edge: Download cheta-chrome.zip, extract it, and select the folder in chrome://extensions (or edge://extensions / brave://extensions) via Load unpacked.
  • Firefox: Download cheta-firefox.xpi (or cheta-firefox.zip), open about:debugging#/runtime/this-firefox, click Load Temporary Add-on..., and select the file.

Build from Source (Developers)

If you prefer to inspect and package the extension from the repository yourself:

git clone https://github.com/Ksschkw/ranti.git
cd ranti
python3 scripts/build_extension.py

The script uses the standard library and outputs:

  • extension-dist/chrome/ for Chrome, Brave, and Edge.
  • extension-dist/firefox/ for Firefox.

Browser Instructions

1. Google Chrome

  1. Open chrome://extensions in your address bar.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked in the top-left corner.
  4. Select the extension-dist/chrome/ folder (or your extracted zip folder).
  5. Click Cheta in your extensions menu to open the Side Panel.

2. Brave Browser

  1. Open brave://extensions in your address bar.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the extension-dist/chrome/ folder.
  5. Launch Cheta from your toolbar.

3. Microsoft Edge

  1. Open edge://extensions in your address bar.
  2. Turn on Developer mode in the left sidebar.
  3. Click Load unpacked in the top bar.
  4. Select the extension-dist/chrome/ folder.
  5. Cheta opens in Edge's native Side Panel.

4. Mozilla Firefox

  1. Open about:debugging#/runtime/this-firefox in your address bar.
  2. Click Load Temporary Add-on...
  3. Select either cheta-firefox.xpi or extension-dist/firefox/manifest.json.
  4. Cheta opens in your Firefox Sidebar. Press Ctrl+Shift+Y (Cmd+Shift+Y on macOS) to toggle.

Store status & Zero Paywalls

Cheta does not publish to the Chrome Web Store or addons.mozilla.org. This avoids developer registration fees, central telemetry requirements, and weeks of opaque store review delays. Running unpacked gives you direct, unadulterated access to Walrus decentralized memory and full WebMCP DOM automation.
