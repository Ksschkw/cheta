Install the extension

The extension is not published to any store yet. It loads from the repository as an unpacked extension, so Chrome and Edge load it unpacked and Firefox loads it as a temporary add-on that must be re-added after a restart.

Get the repository

git clone https://github.com/Ksschkw/ranti.git
cd ranti

The extension lives in the extension/ folder at the top of the repository and contains manifest.json.

Chrome or Edge

  1. Open chrome://extensions. In Edge, open edge://extensions.
  2. Turn on Developer mode, in the top right corner.
  3. Click Load unpacked.
  4. Select the extension/ folder, the one that contains manifest.json.
  5. Open the side panel from the Cheta toolbar button.

Requires Chrome or Edge 114 or newer, because the panel uses the side panel API.

Firefox

  1. Open about:debugging.
  2. Click This Firefox.
  3. Click Load Temporary Add-on.
  4. Select extension/manifest.json.

Firefox keeps a temporary add-on only for the current session. Because the extension is not signed or published, it has to be loaded again after Firefox restarts.

Be aware that the panel is built on the Chromium side panel API and the manifest has no Firefox sidebar entry, so the temporary load currently registers the extension but the panel itself does not open in Firefox. Treat these steps as the loading path, not a working Firefox build.

Store status

There is no Chrome Web Store listing and no addons.mozilla.org listing. The only honest install path today is the unpacked and temporary loading described above.
