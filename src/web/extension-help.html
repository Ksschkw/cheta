Install the extension

The extension is not published to any store. It ships as two unpacked builds from this repository: one for Chrome and Edge, and one for Firefox. Chrome and Edge keep an unpacked extension between restarts. Firefox loads it as a temporary add-on, which is removed when Firefox restarts and has to be loaded again.

Get the repository

git clone https://github.com/Ksschkw/ranti.git
cd ranti

The extension lives in the extension/ folder at the top of the repository. That folder holds the shared code and two manifests: manifest.json for Chromium and manifest.firefox.json for Firefox.

Build the loadable folders

Firefox only reads a file named manifest.json, so the two builds cannot share one manifest. Run the packaging script, which uses the Python standard library and nothing else: 

python3 scripts/build_extension.py

It writes two folders, each a complete extension with its own manifest.json:

  • extension-dist/chrome/ for Chrome and Edge.
  • extension-dist/firefox/ for Firefox.

Re-run the script after any change to extension/, then reload the extension in the browser.

Chrome or Edge

  1. Open chrome://extensions. In Edge, open edge://extensions.
  2. Turn on Developer mode, in the top right corner.
  3. Click Load unpacked.
  4. Select the extension-dist/chrome/ folder, the one that contains manifest.json.
  5. Open the side panel from the Cheta toolbar button.

Requires Chrome or Edge 114 or newer, because the panel uses the side panel API. Loading the extension/ folder directly also works in these browsers, since its manifest.json is the Chromium one; the packaged folder is the recommended path because Chrome and Firefox then read the same shared files.

Firefox

  1. Run python3 scripts/build_extension.py as above.
  2. Open about:debugging.
  3. Click This Firefox.
  4. Click Load Temporary Add-on.
  5. Select the file extension-dist/firefox/manifest.json.

The Firefox build uses the sidebar_action manifest key, so Firefox shows Cheta as a sidebar. The sidebar opens when the add-on loads; if it is closed, open it from View > Sidebar > Cheta, or press Ctrl+Shift+Y (Command+Shift+Y on macOS) to open or close it.

A temporary add-on is removed when Firefox restarts. After every restart, go back to about:debugging, click This Firefox, click Load Temporary Add-on, and select extension-dist/firefox/manifest.json again. Nothing is preserved by the browser across that restart.

The Firefox manifest declares browser_specific_settings.gecko.id. It is not required for Load Temporary Add-on, where Firefox can assign a temporary id, but a stable id keeps the extension's stored settings attached to the same identity across reloads and is required for a signed, permanently installed add-on.

Store status

There is no Chrome Web Store listing and no addons.mozilla.org listing. Neither build is published to any store. The only honest install paths are the unpacked and temporary loading described above.
