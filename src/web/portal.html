CHETA

every chatbot remembers this one decides what to forget

Cheta is a memory-first assistant available on four surfaces that share one memory space per person. It collapses repeated facts, retires things you changed your mind about, and tells you when two things you said conflict.

Four surfaces, one memory

Surface 01

Telegram

Message the bot in Telegram and its memory follows you back to every other surface.

Open the bot

Surface 02

Web widget

Chat in the browser with a live memory count and a per-turn memory switch.

Open the widget

Surface 03

Command line

Install the project and run the terminal client against the same memory. 

python -m pip install -e .
PYTHONPATH=src python -m cli

Surface 04

Browser extension

A side panel that shows the exact memories recalled for every reply.

Install instructions

The extension is not published to any store yet, so this button opens unpacked install instructions rather than a store listing.

What makes it different

  • Visible Memory is readable and correctable in chat: /memories lists it, /forget retires it.
  • Portable A redeployed instance recovers the index from Walrus instead of forgetting everyone.
  • Contradictions Conflicting facts are surfaced to you instead of being silently stored.
  • Counterfactual Any answer can be re-run with memory off, so you can see that it changed.
